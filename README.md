# my_awesome_project

A small script for reading member records from a CSV file and printing each member's full name.

## Requirements

- Python 3, no external dependencies.

## Usage

```bash
python3 read_members.py [csv_path]
```

If `csv_path` is omitted, it defaults to `Members.csv` in the current directory.

## Data

`Members.csv` contains member records with columns: `id`, `first_name`, `last_name`, `email`, `gender`, `ip_address`.
